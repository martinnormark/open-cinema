# Recasting and relocating a moving scene

Tested on **2026-10-18** on Comfy's 8.4 s street-dance clip (720×1280, 24 fps, high-angle camera following a dancer, with a passer-by crossing in front). The ask: change the character, or move the whole scene somewhere else, while the shot keeps moving. Cal (the character-sheet Character) and the Tide Mill Location were the targets. Clips are in the project files under `moving-scene/`. Graphs and requests are under [`evaluation/moving-scene/`](../evaluation/moving-scene/).

## Verdict

| Ask                      | Best result                                                           | Quality                                                                                                                                                                            |
| ------------------------ | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Change the character     | **The app's recast** (Kling 3.0 Omni edit, `video.character-replace`) | 1080p, 24 fps, the real street and the passer-by kept, Cal recognisable (silver hair, charcoal coat, navy sweater). The pre-flight warns `small-face`, and the result held anyway. |
| Move the scene elsewhere | **Seedance 2.5 video edit** through Router (not in the app)           | The whole shot moves to the estuary: ground, water, mill, reflections. The dancer, the passer-by and the camera move are kept. 720p, 24 fps, **8.04 s for an 8.43 s take**.        |
| Both                     | Seedance 2.5 relocate, then the app's Kling recast on its output      | Cal dancing at the tide mill at 1080p with the passer-by. Same 0.4 s shortfall as Seedance.                                                                                        |

The app's **background replacement fails on this much camera motion**. Kling draws the tide mill only while the opening frames match the reference; once the camera pans, the original street comes back. The Bria matte lock cannot fix that, because the edit itself reverts.

## What each pipeline did

| Run                                | Route             | Result                                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| App recast, Kling 3.0 Omni pro     | Router            | Best recast. 9.6 Kling units (about $1.36).                                                                                                                                                                                                                                                                                                                                                                         |
| App background, Kling 3.0 Omni std | Router            | New place for about a second, then back to the source street. 7.2 units.                                                                                                                                                                                                                                                                                                                                            |
| Seedance 2.5 edit, relocate        | Router            | Best relocation; returns 193 frames for 202.                                                                                                                                                                                                                                                                                                                                                                        |
| Seedance 2.5 edit, recast          | Router            | Refused: `content_policy_violation`. Putting a reference face onto a real person in video is blocked.                                                                                                                                                                                                                                                                                                               |
| Wan Animate 2 (open weights)       | Comfy Cloud graph | Animates a still character with the take's motion; the background comes from the prompt. Cal holds well. Needs a reference framed like the shot: a plain full-body image gave a close, cropped result, so FLUX 3 Klein first redraws the opening frame with Cal in the dancer's place. The street is regenerated, the passer-by is dropped. About 80 s of GPU per clip at 480p 16 fps; also run at 544×960, 24 fps. |
| Wan 2.2 Animate, replace mode      | Comfy Cloud graph | Keeps the plate and passer-by at 24 fps via a masked background video. Softer than Kling (544×960) and dressed Cal in black. Its person detector is YOLOv10 (AGPL-3.0), outside our licence list.                                                                                                                                                                                                                   |

## Gaps and what would close them

1. **Relocation on moving takes.** Add Seedance 2.5 video edit as the engine for background replacement when the take moves, keeping Kling plus the lock for small moves. Its result is short (193 of 202 frames), so it needs the conform step to stretch it back onto the take's frame grid, the same way Kling's 24 fps output is conformed.
2. **Recast on small faces.** The `small-face` warning is conservative for Kling 3.0 Omni here; the face was about 3% of frame height and still read as Cal at 1080p.
3. **Partner nodes on Comfy Cloud.** Cloud refuses API nodes (`Please login first to use this node`) unless the request carries `extra_data.api_key_comfy_org`; the app keeps calling partner models through Router.
4. **Router video inputs.** Kling and Seedance fetch video by URL. A Cloud input's `/api/view` redirect is a signed six-hour storage link, usable when R2 has no public URL.
