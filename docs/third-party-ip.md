# Third-party IP

The rule, as Martin set it on 2026-10-17: the app does not rely on other people's IP. A model, LoRA or component is allowed when it is one of these:

1. **Lightricks' own**, under the LTX Community Licenses, since Lightricks makes the LTX base models (their official IC-LoRAs and camera LoRAs included).
2. **Black Forest Labs' FLUX models**, under their FLUX licences. Martin confirmed the FLUX and LTX licences are fine.
3. **Ours**: written or trained in this repository.
4. **MIT or Apache 2.0**, whoever made it.

Creative Commons non-commercial (CC BY-NC) and other non-commercial or unclear licences are out. The competition gives no opening for them: its [page](https://comfy.org/open-source-higgsfield) asks only that the app's code carries "an open-source license and setup instructions" and says "You may use partner models; only the Open Weights Only category requires open-weights models". It says nothing either way about non-commercial model licences (checked 2026-10-17; see [competition.md](competition.md)). Where an MIT, Apache or built-in alternative is easy, it is preferred. Hosted models through Comfy Router are platform services the competition names; Comfy's [terms](https://comfy.org/terms-of-service) say each provider's own terms still apply to them.

Audited on 2026-10-17 against `packages/comfy/src/workflows`, `packages/comfy/src/flux-klein.ts`, `packages/comfy/src/shot-planner.ts`, the jobs Worker registry (`packages/comfy/src/workflows/index.ts`), the studio's on-device models and its bundled code. Each licence links to the page or file it was read from.

## Verdict

- **Recasting stays.** `video.character-replace` runs Kling 3.0 Omni through Comfy Router with the Character's own references and no LoRA.
- **Background replacement stays, on both paths.** The Kling path is Kling 3.0 Omni (with Bria's matte for the as-shot variant) through Router. The LTX path is our own graph around Lightricks' official Alpha Gen IC-LoRA on the LTX 2.5 open weights.
- **Re-stage is rebuilt on our own graph.** It ran on Cseti's CrossView-Prompt IC-LoRA, which was removed. It now re-projects the take through MoGe-2 depth and fills the gaps with Lightricks' official In-Outpainting IC-LoRA ([revision-modes.md](revision-modes.md#how-each-mode-works)). It reaches small moves only; [restage-ic-lora.md](restage-ic-lora.md) is the plan for a re-staging IC-LoRA of our own.

## Code and shaders

- **Studio Orb shader** (`apps/web/src/components/orbs/studio-orb`) is our own, written for Open Cinema and covered by the repository's MIT licence. It replaced the Orb29 shader by XorDev, which carried a non-commercial restriction and has been deleted. The shadercn renderer it runs on (`renderer.ts`, `canvas.tsx`) is MIT as recorded in [LICENSE](../LICENSE); no upstream licence file was found to link.
- `apps/web/src/components/ui` is adapted from shadcn/ui, [MIT](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md).

## Evaluation-only tools

The scripts under `evaluation/` are for Phase 0 scoring and are not shipped in the studio or the Worker. `evaluation/recast/tools/matte.py` uses Ultralytics YOLO11 segmentation ([AGPL-3.0](https://github.com/ultralytics/ultralytics/blob/main/LICENSE)) and `evaluation/recast/tools/identity.py` uses insightface's `buffalo_l` face models, which are for non-commercial research only ([README](https://github.com/deepinsight/insightface#license); the code is MIT). Neither may move into the product.

## What was removed

- **Cseti's CrossView-Prompt IC-LoRA**, Re-stage's former model. Its graph, prompt builder and model entry are deleted; Re-stage now runs on the graph described above.
- **Depth Anything V2 Large** (CC BY-NC 4.0), the Object Swap and Restyle depth guide. MoGe-2 (MIT) renders the depth instead.
- **DWPose** (Apache 2.0), the pose guide in performance transfer and the LTX recast experiment. It was allowed, but an edge guide needs no weights at all: ComfyUI's core `ImageBlur` and `Canny` nodes make it instead.
- **Orb29 shader** by XorDev (non-commercial). The Studio Orb, our own shader, replaced it.
- Every LoRA still in use is Lightricks'. The Cameraman IC-LoRA had already been passed over for its non-commercial licence.
