# Task map

What a creator arrives wanting, in their words, and the best workflow behind it today. The front page (`apps/web/src/features/start`) offers exactly the goals in the first two tables; the third lists goals we do not offer yet and what would earn them a place. Recorded on 2026-10-18 from the comparisons in this folder.

Elements are what make each result the creator's own: a Character carries a face and wardrobe, a Location a place (and its moving reference), a Thing a prop. A goal names the Element type that feeds it, and the front page lets the creator pick one before the take lands in the revision studio (`/revisions/new?kind=…&source=…&element=…`).

## Front page rules

- The first list stays short: the seven take goals creators ask for most, then "More" for effects, restyle and re-staging. A goal chosen from a link opens "More" so it is never hidden.
- A goal is one line of title and one sentence of result. Take goals use the revision studio's mode names so the two screens read alike.
- The first action is a take (drop, choose a file, or one of your clips) or an Element. Nothing else on the page competes with it.
- A goal that needs an Element shows the creator's own; with none, it offers to make one.
- `apps/web/test/start-goals.test.ts` fails if a revision mode has no goal, so a new mode cannot ship without a way in.
- The sidebar holds Start, Studio, Elements, Sequences and Library (decided 2026-10-18). Activity opens from the Orb, Recipes from Studio, and Projects from Sequences.
