# Open Source Higgsfield competition

Verified **2026-10-16** against the [competition landing page](https://comfy.org/open-source-higgsfield) and [Comfy announcement](https://blog.comfy.org/p/higgsfield-promised-to-open-source), published October 15, 2026 by Allyson Toy.

## Purpose and entry point

Build a working creative application using the Comfy Developer Platform, with a usable interface and example outputs. Comfy invites open-source recreations of popular creative tools, including Genjutsu and Cinema Studio, as well as original ideas. The announcement advertises approximately **$25,000 in prizes**, backed by NVIDIA AI, Runpod, LTX, Black Forest Labs, and MiniMax.

The campaign's claim about Higgsfield's open-source promise is Comfy's framing, not an independently verified finding in this research.

**Submit through the [official entry form](https://form.typeform.com/to/V1dSQrkS).**

## Submission checklist

- [ ] Build a working creative app with an interface and example results.
- [ ] Use **Comfy API, Comfy Router, and/or Comfy SDK** as required by the competition.
- [ ] Publish a GitHub repository containing the application code and workflow files.
- [ ] Include an open-source license and sufficient instructions for someone else to run it locally.
- [ ] Prepare a demo video lasting **no more than two minutes**, showing the app and explaining how it was built.
- [ ] Explain any additional tools, models, or techniques in the video; for Most Innovative, explicitly explain the innovation.
- [ ] Post the demo on Reddit, X, Instagram, LinkedIn, YouTube, or TikTok using **#OpenSourceHiggsfield**, and include the social-post link.
- [ ] Optionally provide a deployed app or endpoint to try; this is strongly encouraged.
- [ ] Submit the entry form before the deadline. **One submission per person.**

The landing page requires lawful, SFW submissions without unlicensed intellectual property or likenesses. Submitting grants ComfyUI, NVIDIA, Runpod, LTX, Black Forest Labs, and MiniMax permission to feature the work with credit. Partner models are permitted generally; the Open Weights Only category has the additional restriction above. Video production quality is not the judging focus.

Source: [How to enter, requirements, and Q&A](https://comfy.org/open-source-higgsfield).

## Source notes and unresolved details

The landing page supplies the full timeline and submission requirements. The announcement embeds its key dates in an image; the dates above were read from the landing page's text. The announcement's event heading mentions NYC, but its body and the landing page provide only SF and LA registrations; no NYC event is confirmed here.

The reviewed pages do not specify numerical judging weights, a viral-metric threshold, geographic/age eligibility, team-entry rules, or how ties are resolved. The Open Weights Only phrase “no partner nodes or APIs” is not further defined there; do not infer that it forbids the Comfy workflow APIs required elsewhere. Check with the organizer if that distinction affects the entry. The entry form is linked here but was not submitted or exhaustively audited for additional terms.
